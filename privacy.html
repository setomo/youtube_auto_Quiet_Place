Privacy policy

Quiet Place · last updated 12 October 2026

This application collects no data from anyone. It is a personal command-line tool with a single user — its operator — running on one personal computer. There is no server, no database of users, no analytics, and no third party receives anything.

Who this covers

One person: the operator, publishing to their own YouTube channel. Nobody else can authorise an account with this application, so there is no other person's data for it to handle.

What Google data it accesses

Only the operator's own Google account, and only to publish to the operator's own channel.

ScopeUsed for
youtube.upload Uploading a finished video file
youtube Setting title, description, privacy and scheduled publish time; adding the video to a playlist
youtube.force-ssl Attaching the caption track. The captions endpoint requires this scope specifically
yt-analytics.readonly Reading view counts for the operator's own videos

What is stored, and where

  • An OAuth refresh token, in a file on the operator's own computer (secrets/youtube_token.json), so the tool does not have to ask for authorisation on every run.
  • A record of which videos were uploaded and what privacy setting was requested for each, so unintended changes can be detected.
  • A count of API quota used today.

All of it stays on that computer. None of it is transmitted anywhere, and none of it is backed up to any service.

What is sent out

Only to Google, and only on the operator's instruction: the video file, its title, description, tags, caption file, and privacy or scheduling setting. Nothing else leaves the machine.

What is not done

  • No data is sold, shared, or disclosed to any third party.
  • No analytics, telemetry, tracking or advertising, of any kind.
  • No data about any person other than the operator is collected, inferred or stored.
  • No Google user data is used to train any machine-learning model.
  • No access to Gmail, Drive, Contacts, Calendar, or any Google service beyond the YouTube scopes listed above.

Retention and deletion

The stored token remains until deleted. The operator can revoke access at any time at myaccount.google.com/permissions, which invalidates it immediately, and can delete the local file to remove it entirely.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

If this policy changes, the revised version will be published on this page with a new date.
